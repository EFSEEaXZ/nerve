# nerve 0.8.0

- Панель и Windows-трей в одной светлой/тёмной палитре; Onest включён локально.
- Кастомный скроллбар, рабочие Close/Cancel/Escape в окне установки скиллов, восстановление фокуса и защита от позднего ответа закрытого окна.
- Обновления из стабильных GitHub Releases этого репозитория: SHA-256, проверка версии, фоновая загрузка и установка после паузы в MCP-активности. Поле произвольного URL убрано из панели.
- Быстрый JSON для коротких вызовов, SSE для долгих, сохранение больших ответов в файл и очистка неактивных сессий.
- Общий пример конфига без учётных данных. Каждый пользователь подключает собственный туннель и задаёт собственный PIN.

Нужен Windows x86-64. Для Python-плагинов и внешних приложений требуются их отдельные установки. Бинарник не подписан сертификатом Windows; Onest распространяется под SIL OFL.
