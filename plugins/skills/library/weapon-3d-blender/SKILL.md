# Реалистичное оружие в Blender: процедурно, по референсу, с обязательной проверкой рендерами

Скилл написан по итогам реальной работы (катана + M4A1). Аниме/стилизованные скиллы для реализма НЕ подходят — не смешивай.

## 0. Главное правило (цикл)
**сделал → отрендерил несколько ракурсов → посмотрел КАЖДУЮ картинку → сравнил с референсом → исправил 1–3 самые заметные вещи → повторил.**
- Модель = скрипт `build_<item>.py`, который пересобирает сцену с нуля за секунды. Правки делаются в скрипте, не руками в сцене → версии воспроизводимы.
- Каждая итерация — новый файл: `item_v01.blend`, `item_v02.blend`…, рендеры в `renders/vNN/`.
- Не говорить «готово», пока не просмотрены все рендеры последней версии (общий план + крупные планы узлов).
- Приоритет правок: (1) силуэт/пропорции, (2) материалы и свет (тон/яркость как на фото), (3) скругления/формы, (4) мелкие детали и маркировки.

## 1. ТЗ (коротко, с допущениями)
Тип, эпоха/модель, комплектация, размеры в мм (из спецификаций), материалы. Если пользователь сказал «на своё усмотрение» — не спрашивай, а запиши допущения (например: «M4A1 с RAS KAC, M68 CCO, сложенный BUIS, магазин USGI 30»).

## 2. Окружение (dd MCP + Blender)
- Blender: `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`. Сборка: `blender -b --factory-startup -P build_x.py -- --out X.blend`.
- **Таймаут запроса MCP ≈ 60 с.** Всё, что дольше (рендеры), запускай `exec {argv:[...], background:true}` и опрашивай `job {action:"logs", id}`. `job wait` тоже упирается в 60 с — используй `logs`.
- Смотреть картинки: `image {paths:[...], format:"jpeg", max_dim:1800}`. Смотри сам каждую.
- Скрипты кладутся в проект (`<project>\scripts\`), библиотеки импортируются через `sys.path.insert(0, HERE)` + `importlib.reload`.
- Без `--factory-startup` грузятся аддоны пользователя (tripo, MCP-сервера) — для фоновых рендеров лучше с ним; render_views сам включает GPU (OptiX/CUDA).

## 3. Конвенции
- Метры 1:1 (в скриптах удобно мм × 0.001). Длинная ось = +Z (остриё/дуло вверх), «лицевая» сторона смотрит в −Y, origin — центр рукояти. Все части — отдельные именованные объекты в одной коллекции (`katana`, `m4a1`). Нормали наружу (mk(fix=True) пересчитывает).
- Огнестрел удобно строить в «оружейной» системе: X вперёд (к дулу), Y влево, Z вверх, ось канала = ось X, X=0 — передний торец ствольной коробки. В конце один поворот `R = ((0,0,-1),(0,1,0),(1,0,0))` (вперёд→+Z, верх→−X, левая сторона→+Y) и перенос origin в центр пистолетной рукояти.

## 4. Референсы и размеры
- Найди боковой вид с прозрачным фоном (Wikimedia «M4A1-flattop.png» и т.п.). Посчитай мм/пиксель по известной длине (M4A1 со сложенным прикладом 757 мм; катана: нагасa ~70 см, цука ~25 см).
- **Трассировка силуэта**: альфа-канал → OpenCV `findContours` → полигоны деталей (приклад, рукоять, магазин) в мм → JSON (`m4a1_outlines.json`). Кадрируй узлы с сеткой (crop + grid) и снимай координаты ключевых точек (рейка, ось канала, мушка, магазин).
- Проверяй итог наложением рендера `beauty` на референс в том же масштабе.

## 5. Геометрия: приёмы (wlib.py)
- `lathe(profile)` — тела вращения (ствол, пламегаситель, гайки, оптика, кнопки). Профиль (x, r) с фасками 0.3–0.6 мм.
- `prism(poly, y0, y1)` — плоские детали из бокового контура (ствольная коробка, спуск, скоба). `slab()` — призма в произвольной плоскости (прорези, вырезы).
- **`clean_outline(P, eps, corner_deg)`** — ОБЯЗАТЕЛЬНО для трассированных контуров: RDP + Чайкин с сохранением острых углов. Иначе bevel даёт «молнию»/зубцы по краям.
- **`pillow(poly, half, r_edge)`** — скруглённое «подушкой» тело из контура (CDT `mathutils.geometry.delaunay_2d_cdt` + кольца + эллиптический профиль). Для пистолетных рукояток, накладок, мягких форм. Призма+bevel выглядит как CAD-брусок.
- **Булевы**: резаки одной операции объединяй в один меш (`cut(ob, [parts])`). Если куски резака пересекаются — нужен EXACT + `use_self=True` (иначе объект «исчезает»: RAS цевьё стало длиной 1 мм). Отверстие + прорези вентиляции — отдельные операции или use_self.
- Модификатор Bevel создаётся до булевых, boolean() применяет только себя и ставится первым → фаска остаётся «живой» и скругляет новые рёбра. UNION (`op='UNION'`) приливов (корпус досылателя, отражатель гильз, горловина магазина) + живой bevel = литые/фрезерованные галтели вместо «приклеенных» деталей.
- После булевых `assign(ob, mat, replace=True)` чистит слоты (булевы тащат материалы резаков → белые грани).
- Planka Picatinny (MIL-STD-1913): профиль ±7.6/±10.6/±7.85 при высотах 0/3.65/6.65/9.4 мм, шаг 10.01, паз 5.23, одна булева со всеми пазами.
- Насечки ручек: `knurl_ring` (звёздочка) призмой; рифление на рукояти — шейдером (bump), не геометрией.
- Маркировки: текст Blender (`bpy.data.curves.new(type='FONT')`, Arial Bold) → `new_from_object` → меш толщиной 0.08 мм, наполовину утоплен в поверхность. Выбитые клейма — материал чуть светлее (0.13), номера RAS — белая краска (0.6).

## 6. Материалы (Cycles Principled, процедурно, без текстур)
Холодное оружие:
- Полированная сталь: metallic 1, base 0.50–0.63 (ji), roughness 0.08–0.15, анизотропные риски шлифовки шумом. Хамон: волна по фазе/амплитуде шума (gunome/choji), размытая граница (nioi) + искры (nie) Voronoi. Хабаки — латунь/медь с мелкими рисками.
- Ито (оплётка): тёмно-синий, мелкий твил + волокно, sheen 0.10, spec 0.35 — без этого похоже на пластик.
- Самэ (кожа ската): ДВА смещённых слоя Voronoi F1 «куполов» (радиусы .56/.48), щели тёмные (0.44,0.40,0.32). Distance-to-edge даёт сетку, а не бугорки.
- Цуба железо: тёмная патина + ржавчина-пятна, канавка по ободу, прорези.
Огнестрел (тёмные финиши — светлота главный признак реализма):
- Анодированный алюминий: base ≈0.05, roughness 0.50, metallic 0.15, износ по рёбрам (Bevel-node маска × AO) светлее 0.5.
- Фосфат (паркеризация): base ≈0.042 серо-зелёный, roughness 0.62, metallic 0.3.
- Полимер: base 0.034, roughness 0.70, spec 0.35 (иначе на скользящих углах верх приклада белый).
- Рукоять: тот же полимер + алмазная насечка bump, маска по |N.y| (только плоские боковые панели).
- Магазин USGI: 0.06, roughness 0.5; широкие низкие рёбра 6.5 мм × 0.7 мм.
- Пятнистость (mottle) ≤ 0.07–0.1 и крупная; сильный шум = «бетон».
- Оптика: чёрный анод 0.02 rough 0.34, резина 0.82, линзы — coat 1, thin film 420 нм.

## 7. Свет и рендер (render_views.py)
```
blender -b X.blend -P render_views.py -- --out renders/v03 --res 1800 --collection m4a1 \
  --views beauty,beauty_back,three_quarter,top --samples 96 \
  --focus "receiver=upper_receiver,lower_receiver@12,8,h;left=lower_receiver,roll_marks@168,8,h" \
  --softbox 0.6 --exposure -0.6 --bg 0.30 --world-up view
```
- Мир 'neutral' — процедурная серая студия (градиент + верхняя полоса). Тёплые HDRI красят полированную сталь в жёлтый — не использовать для клинков.
- `--softbox F` — большая градиентная светящаяся карта у камеры (невидима камере/теням). Без неё зеркальный клинок рендерится чёрным/тёмным. Для катаны 1.0, для огнестрела 0.6.
- Тёмное оружие: `--exposure -0.6 --bg 0.30` (оружие тёмно-серое, фон светлый, как на фото).
- `--world-up view` — верх студии следует за «верхом» камеры. Для горизонтальных кадров винтовки (camera up = −X) обязательно, иначе свет «сверху» приходит со стороны дула.
- Виды: beauty/beauty_back — горизонтальные «витринные» (рукоять слева), **hero/hero_back** — горизонтальные 3/4 презентационные (30° к дулу, 18° сверху; лучший кадр для показа), three_quarter, front/side/top, closeup_*; `--focus name=objs@az,el[,h]` — крупные планы 85 мм; `h` = горизонтально (az к дулу/острию, el к верху; az=168 — левая сторона).
- 1800–2400 px, 96–128 сэмплов, рендер ~10 с/вид на GTX 1660 Ti. Отчёт объектов (габариты, полигоны) печатается в лог — сверяй размеры.

## 8. Подводные камни (реально случились)
1. MCP-таймаут 60 с — длинные операции только фоном (`background:true` + `job logs`).
2. Пересекающиеся куски резака без use_self → булева уничтожает объект.
3. Материал после булевой: слоты резака → белые грани (лечится assign(replace=True)).
4. Трассированные контуры с пиксельным шумом + bevel = зубцы → clean_outline.
5. Тёплый HDRI → сталь желтеет; низкая яркость окружения → ji катаны чёрный → нейтральная студия + софтбокс + base стали 0.55–0.6.
6. Чёрное оружие в яркой студии выглядит серым пластиком → уменьши экспозицию, подними фон; пятнистость материала ≤0.1.
7. Мировой градиент по +Z не совпадает с «верхом» горизонтального кадра → `--world-up view`.
8. Скользящие блики на верхних гранях (рейки, приклад) — Fresnel; лечится roughness 0.6–0.7 и spec 0.35 для полимера.
9. `o.dimensions` после `mesh.transform` может быть устаревшим — для сверки размеров смотри отчёт render_views (evaluated).
10. Детали «приклеены» (цилиндр на коробке) — делай UNION в основной объект и пусть bevel скруглит стык.

## Lessons learned

- [2026-10-13] (worked) Katana v06 (994 mm, 143k polys) + M4A1 v03 (757 mm, 79.5k polys) built with this skill. Final hero shots: katana --softbox 1.0 defaults; M4 --softbox 0.6 --exposure -0.6 --bg 0.30 --world-up view. Long renders (2400 px, 128 spp) must run with background:true and be polled via job logs.
- [2026-10-13] (tip) Для реалистичной игровой low-poly версии готового high-poly нужен отдельный этап оптимизации и запекания. Проверенный кейс Nocturne: 12232 tris, UV/PBR bake, GLB round-trip. Не переносить тонкую инкрустацию геометрией и не путать красивый рендер со стилизованным угловатым low-poly.
- [2026-10-13] (tip) Name exterior mechanical parts semantically and retain their author-to-canonical transform metadata; moving-part ownership and pivot bases must survive the low-poly stage. Keep visual animation in a separate animation/ directory for shot, swing-cylinder reload, projectile macro, GLB round-trip and keyed studio VFX. The static artwork should stay untouched; hands, collisions, sound and engine gameplay need separate work.
